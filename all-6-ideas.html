How to Import Any Screen Into Figma

  1. Pick one of the 6 ideas above and switch between Desktop and Mobile (390px) to test the layout.
  2. Download or save this HTML file to your computer, or open it in Chrome.
  3. Open Figma (free student plan) and install the free plugin html.to.design.
  4. Run the plugin in Figma, drop this HTML file (or paste the live preview), and click Import.
  5. Every heading, table, button, and input turns into editable Figma layers (ស្រទាប់ដែលអាចកែបាន) ready for your FST Phase 3 SDD!
